# Altoura – Unity AR Assignment

## Unity Version
Unity 6000.3.8f1

---

## Packages / Importer Used

- AR Foundation
- ARCore XR Plugin (Android)
- XR Plugin Management
- XR Interaction Toolkit
- glTFast (Khronos Group official GLB/glTF importer, added via Git package)

---

## How to Run

1. Open the project using Unity 6000.3.8f1.
2. Switch platform to Android:
   - File → Build Settings → Select Android → Switch Platform.
3. Ensure ARCore is enabled:
   - Project Settings → XR Plugin Management → Android → ARCore checked.
4. Connect an ARCore-supported Android device.
5. Click **Build and Run** to generate and install the APK.
